# 안효민 포트폴리오

자율주행로봇 필드엔지니어 직무 지원을 위해 제작한 개인 포트폴리오 사이트입니다.
현장에서 문제를 확인하고, 원인을 나누어 점검하며, 조치 내용을 기록해 고객과 개발팀이 이해할 수 있게 전달하는 역량을 중심으로 구성했습니다.

배포 주소: https://purejuly.github.io/PureJuly/

## 소개

이 포트폴리오는 아래 내용을 한눈에 확인할 수 있도록 정리했습니다.

- 자율주행로봇 필드엔지니어 지원 방향
- 현장 이슈를 확인하고 해결로 연결하는 방식
- 학습 과정과 회사 생활에서 쌓은 기본 역량
- 완료한 프로젝트 2개와 상세 설명
- 이메일 및 GitHub 연락처

## 프로젝트 구성

### 1. 스마트 분리수거 쓰레기통

객체 인식, RFID 인증, 블루투스 통신, DB와 웹 대시보드를 연결한 분리수거 시스템 프로젝트입니다.

담당 작업:

- HuskyLens 객체 인식 데이터셋 준비 및 학습
- RFID 태그 UID 검증 흐름 구성
- Arduino와 Raspberry Pi 간 블루투스 통신 연결
- SQLite 기반 인증 DB 및 사용 기록 관리
- 웹 대시보드 서버 개발과 통합 디버깅

상세 페이지: `project-smart-bin.html`

### 2. 공기질 연동 자율주행 공기청정 로봇

미세먼지 센서, MQTT 통신, ROS2 기반 자율주행, 웹 대시보드를 연결한 실내 공기질 관리 프로젝트입니다.

담당 작업:

- Arduino, ESP-01, PMS7003 기반 센서 모듈 조립
- 전원부와 배선 상태 점검
- 통합 테스트 과정에서 하드웨어 동작 상태 확인
- 시스템 유지보수 및 문제 대응
- 프로젝트 시연 영상 제작

상세 페이지: `project-air-robot.html`

## 실행 방법

별도의 설치나 빌드 과정은 필요하지 않습니다.

1. 저장소를 내려받습니다.
2. `index.html` 파일을 브라우저에서 엽니다.
