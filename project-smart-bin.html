Overview

프로젝트 개요

공동주택이나 기숙사처럼 여러 사람이 함께 사용하는 공간에서는 잘못된 분리배출이 반복되기 쉽습니다. 이 프로젝트는 사용자가 쓰레기를 올리면 HuskyLens 카메라가 종류를 인식하고, RFID 인증을 거쳐 해당 쓰레기통을 자동으로 여는 구조로 설계했습니다. 사용 기록과 쓰레기통 상태는 Raspberry Pi 서버와 웹 대시보드에서 확인할 수 있도록 구성했습니다.

My Role

내가 맡은 작업

객체 인식 데이터셋 준비 및 학습

플라스틱, 종이, 일반쓰레기를 구분할 수 있도록 HuskyLens 학습 데이터를 준비하고 인식 결과가 실제 개폐 흐름으로 이어지는지 테스트했습니다.

RFID·블루투스 통신 기능 개발

RFID 태그 UID를 확인하는 흐름을 만들고, Arduino와 Raspberry Pi가 HC-06 블루투스로 인증 결과와 동작 데이터를 주고받도록 연결했습니다.

인증 DB 및 래퍼 서버 개발

SQLite DB에 사용자 인증 정보와 사용 기록을 저장하고, 장치 제어 코드가 DB에 접근할 수 있도록 래퍼 서버 구조를 구성했습니다.

웹 대시보드 서버 개발

관리자 입장에서 로그 조회, 상태 확인, 사용자 관리가 가능하도록 웹 대시보드 서버를 개발하고 개별 기능을 통합하는 과정에서 디버깅을 진행했습니다.

Flow

구현 흐름

01
인증과 입력 대기

RFID 태그 UID를 확인한 뒤, 인증된 사용자인 경우에만 쓰레기 분류 단계로 넘어가도록 흐름을 구성했습니다.

02
쓰레기 종류 인식

HuskyLens가 인식한 결과를 기준으로 플라스틱, 종이, 일반쓰레기 중 어떤 쓰레기통을 열지 판단했습니다.

03
개폐·포화 상태 기록

Arduino가 서보 모터와 초음파 센서를 제어하고, Raspberry Pi 서버가 사용 로그와 상태 정보를 저장하도록 연결했습니다.

Problem Solving

문제 해결 과정

문제

객체 인식 모델이 플라스틱, 종이, 일반쓰레기만 학습했을 때 쓰레기가 없는 빈 공간도 특정 쓰레기로 잘못 판단하는 문제가 있었습니다.

해결

“쓰레기 없음” 상태를 별도 클래스로 학습시켜 오인식을 줄였고, 해당 결과를 동작 종료 조건으로 활용해 불필요한 개폐가 발생하지 않도록 조정했습니다.

추가 개선

좁은 쓰레기통 내부에서 초음파 센서값이 흔들리는 문제는 임계값을 분리하고 센서 안정화 대기 로직을 두는 방식으로 개선 방향을 잡았습니다.

Stack

사용 기술

Raspberry Pi

RFID 인증 결과를 처리하고 SQLite DB, 웹 대시보드 서버, Arduino 통신 흐름을 연결하는 중심 장치로 활용했습니다.

Arduino

서보 모터와 초음파 센서를 제어하고, 쓰레기통 개폐와 포화 상태 감지를 담당하는 하드웨어 제어부로 사용했습니다.

Bluetooth

Arduino와 Raspberry Pi 사이에서 분류 결과, 인증 결과, 동작 상태를 주고받기 위한 무선 통신 방식으로 구성했습니다.

SQLite

RFID 사용자 정보와 사용 로그를 저장하고, 대시보드에서 조회할 수 있는 데이터 기반으로 활용했습니다.

Result

결과와 성장 포인트

객체 인식, RFID 인증, 블루투스 통신, DB, 웹 대시보드가 하나의 흐름으로 연결되는 시연 시스템을 완성했습니다. 이 과정에서 장치가 정상 동작하지 않을 때 카메라 인식, RFID 통신, 블루투스 송수신, DB 저장 위치를 나누어 확인하는 습관을 얻었습니다. 필드엔지니어 업무에서도 현장 장비와 소프트웨어 흐름을 함께 보고 문제 범위를 좁히는 태도로 연결할 수 있는 경험입니다.
